# Pasal 13
(1) Stasiun kereta api sebagaimana dimaksud dalam Pasal 9 huruf b, berfungsi untuk:
a. keperluan naik turun penumpang dan/atau bongkar muat barang;
b. keperluan operasi kereta api;
c. keperluan pergantian antar moda.
(2) Stasiun kereta api wajib dilengkapi dengan fasilitas untuk:
a. naik turun penumpang;
b. bongkar muat barang;
c. operasi kereta api;
d. fasilitas umum lainnya.
(3) Fasilitas sebagaimana dimaksud pada ayat (2), harus memenuhi persyaratan:
a. keselamatan, kenyamanan dan kemudahan untuk penumpang;
b. keselamatan dan kemudahan untuk bongkar muat barang;
c. keselamatan dan keamanan operasi kereta api.
