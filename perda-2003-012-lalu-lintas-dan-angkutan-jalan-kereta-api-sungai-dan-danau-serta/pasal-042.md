# Pasal 42
(1) Pemeriksaan dan pengujian sarana kereta api dilaksanakan untuk pertama kali sebelum dioperasikan dan selanjutnya secara berkala sekurang-kurangnya sekali dalam 1 (satu ) tahun.
(2) Sarana kereta api sebagaimana dimaksud pada ayat (1), yang telah lulus pemeriksaan dan pengujian diberikan tanda lulus.
(3) Pemeriksaan dan pengujian prasarana kereta api, khususnya untuk jalan rel termasuk jembatan dan terowongan, peralatan persinyalan, instalasi listrik dan peralatan telekomunikasi, dilakukan sekurang-kurangnya sekali dalam 1 (satu ) tahun.
