# Pasal 15
(1) Pada setiap stasiun kereta api ditetapkan daerah lingkungan kerja dengan batas-batas tertentu yang jelas.
(2) Batas-batas daerah lingkungan kerja stasiun kereta api sebagaimana dimaksud pada ayat (1), ditetapkan dengan Keputusan Gubernur setelah mendapat pertimbangan dari pejabat yang berwenang di bidang pertanahan.
