# Pasal 82
(1) Penyediaan prasarana dan sarana kereta api termasuk pembangunan dan pengoperasian dilaksanakan oleh Kepala Dinas Perhubungan.
(2) Penyediaan prasarana dan sarana kereta api sebagaimana dimaksud pada ayat (1), dapat dilaksanakan oleh pihak ketiga.
(3) Ketentuan lebih lanjut mengenai penyediaan sebagaimana dimaksud pada ayat (2), ditetapkan dengan keputusan Gubernur.
