# Pasal 40
(1) Perawatan sarana dan prasarana kereta api dilakukan oleh Dinas Perhubungan dan dapat dilaksanakan oleh pihak ketiga dengan persetujuan Gubernur.
(2) Ketentuan lebih lanjut mengenai perawatan sarana dan prasarana kereta api sebagaimana dimaksud pada ayat (1), ditetapkan dengan keputusan Gubernur.
