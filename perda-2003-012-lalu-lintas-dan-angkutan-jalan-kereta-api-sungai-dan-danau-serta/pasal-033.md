# Pasal 33
(1) Setiap pengusahaan bengkel umum untuk pengujian berkala dan/atau karoseri kendaraan bermotor wajib mendapat izin pengusahaan dari Gubernur.
(2) Untuk mendapatkan izin pengusahaan sebagaimana dimaksud pada ayat (1), wajib mendapat rekomendasi teknis dari Dinas Perhubungan.
