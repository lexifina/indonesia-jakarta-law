# Pasal 36
(1) Sarana kereta api berdasarkan fungsinya terdiri dari:
a. sarana penggerak;
b. sarana pengangkut penumpang atau barang;
c. sarana untuk keperluan khusus.
(2) Sarana kereta api sebagaimana dimaksud pada ayat (1), harus sesuai dengan spesifikasi prasarana kereta api yang berlaku.
