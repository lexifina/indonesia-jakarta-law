# Pasal 83
(1) Pengusahaan prasarana dan sarana kereta api dapat dilakukan oleh:
1. Badan Usaha Milik Negara (BUMN) atau Badan Usaha Milik Daerah (BUMD);
2. Badan usaha milik swasta;
3. Koperasi.
(2) Pengusahaan prasarana dan sarana kereta api wajib mendapat izin dari Kepala Dinas Perhubungan.
(3) Pengusahaan prasarana dan sarana kereta api sebagaimana dimaksud pada ayat (1), dilaksanakan dengan memperhatikan:
a. kepentingan pelayanan umum;
b. keselamatan operasi kereta api;
c. keamanan dan ketertiban dalam pelayanan jasa;
d. kelangsungan pelayanan;
e. kenyamanan penumpang.
